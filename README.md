# VESTA TEM

Cyberpunk glassmorphism Canva-template store. Vite + React + Tailwind frontend, Supabase backend (magic-link auth, Postgres, Edge Function `api`), hosted on Vercel.

## Develop
    npm install
    npm run dev

Optional env: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` (defaults are baked in).

## Deploy
Vercel builds with `vite build` and serves `dist`.
